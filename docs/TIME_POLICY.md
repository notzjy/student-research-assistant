# 时间解释规则与后续解析方案

记录日期：2026-10-16。用户已完成第十课参考时间练习，并提出裸星期的默认解释。本文件区分用户规则、设计示例和当前已实现能力。

## 已确认的规则

- 相对表达以原消息发送时刻为基准，先换算到当前业务规定的北京时间。延迟处理、补同步和重放消息不改变这个基准。
- 用户规定裸“周三”等按原消息所在周的对应星期解释；本项目将自然周按周一至周日计算。“周四”等同类表达遵循相同规则。
- 即使目标星期已经过去，也不为了得到未来日期而自动跳到下周；“下周三”则需要显式的下周含义。
- 按此规则，“周三前”的日期也采用本周三。没有钟点时仍不补造23:59；后续需要精确截止提醒时，只补充确认钟点，不重复询问属于哪一周。

裸“周三”可以先确定日期，无需为了记录日期而补钟点或反复追问。第十一课新解释接口已支持日期精度；若创建精确到分钟的提醒，才需要相应钟点或用户另外配置的默认提醒规则。用户尚未配置默认提醒钟点。

## 统一基准下的设计示例

以下固定以消息发送时间 `2026-10-16T20:00:00+08:00` 为基准。它是星期五。

| 原表达 | 对应日期或日期范围 | 精度 |
| --- | --- | --- |
| 昨天 | 2026-10-15 | 日期 |
| 周三 | 2026-10-14，不自动变成10月21日 | 日期 |
| 周四 | 2026-10-15，不自动变成10月22日 | 日期 |
| 这周 | 2026-10-12至2026-10-18，包含两端日期 | 一周范围 |
| 下个月 | 2026-11-01至2026-11-30，包含两端日期 | 一月范围 |
| 今年 | 2026-01-01至2026-12-31，包含两端日期 | 一年范围 |

这些表达不都对应一个精确时刻。第十一课通过模型意图和通用运算实现上表样例，并分别返回日期、日期范围或精确时刻；完整的绝对日期时间继续由第十课有限规则接口直接校验，不按参考日期再次平移。

## 后续怎样减少手写规则

第十课的有限规则用于展示参考时间、日期加减、时区和校验。第十一课已把表达归纳为日偏移、星期定位、月偏移、年范围等通用结构，由模型给出候选，再由程序执行日历运算、应用用户规则并校验。后续还可结合经过样本验证的解析库。月份变化不能简单视为增加30天。

成熟解析器可以复用现成能力，例如 dateparser 提供 `RELATIVE_BASE` 指定参考时刻，以及不完整日期和时区设置。其默认补全策略需要与本项目的精度及星期规则对照，不能直接把库补出的钟点当成用户说过的事实。[dateparser 官方设置文档](https://dateparser.readthedocs.io/en/stable/settings.html)

第十一课已采用模型先给出“本周、星期三、无钟点”等结构候选，再由Python计算的路径。Python检查日历与关键项目规则，Pydantic检查字段和精度；这些检查仍不能证明所有模型语义都正确。额外解析库需用本项目中文样本验证后选择，目前没有新增依赖或替换第十课后端。

## 一个覆盖所有星期的公式

下面只是展示通用计算的可运行示例；参考值已是北京时间，所以可以直接取日期：

```python
from datetime import datetime, timedelta

reference = datetime.fromisoformat("2026-10-16T20:00:00+08:00")
target_weekday = 2  # 星期一为0，星期三为2，星期日为6。

# 不使用取模或自动加7，保留本周已过去的目标日期。
target_date = reference.date() + timedelta(days=target_weekday - reference.weekday())
print(target_date)  # 2026-10-14
```

只改变 `target_weekday` 就覆盖周一至周日，无需为每个星期写一个函数。这条公式描述日期定位，不指定提醒钟点。

## 当前实现边界

`lessons/time_parser.py` 与 `/time/normalize` 保留第十课有限规则与协议。第十一课新增 [time_semantics.py](../lessons/time_semantics.py)、[讲义](../lessons/11_README.md) 和 `/time/interpret`：模型提取相对时间意图，程序计算日/周/月/年，Pydantic判别联合区分minute、date、date_range与unresolved。请求必须提供原消息时间；结果保留原文、参考原字符串和固定UTC+08业务时区。

对精确匹配的裸“周三”“星期三”“周三前”等，程序强制本周日期政策并去除模型误补的钟点。其他复杂表达的含义及钟点提取仍依赖模型，尚未实现通用语义正确性保证。日期范围包含两端日期，不代表具体钟点；日期级deadline没有补成00:00或23:59。
