## 早期练习：从通知到数据

作用：原始消息可以完整地交给模型，同时提供来源、发送时间与时区等背景。模型提取事项后，程序需要明确字段来保存、显示、提醒以及分别修改或取消。结构化就是将理解结果变成可保存、可校验、可计算的信息；字典练习是在设计模型应返回什么，不是要求用户先手工拆消息才能调用模型。Python 和 JSON 的语法会在使用前解释。

练习（已部分作答，按步骤继续）：

假设导师于北京时间 2026-10-15 20:00 发来：

> 明天下午三点在实验楼302开组会；周五前交综述，附件是两篇参考论文。

1. 这条消息应拆成几项事项？为什么不宜只保存一个 `time` 字段？
